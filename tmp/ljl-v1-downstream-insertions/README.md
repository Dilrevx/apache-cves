# Strict v1 Downstream Insertion Dataset

This directory is the lightweight published view of the strict vulnerability-triangle dataset.

A confirmed row means: generated vulnerable upstream v1 dependency -> inserted into a real downstream runtime/classpath -> triggered through the downstream project own entrypoint -> positive/negative dynamic evidence.

The full extracted runtimes and bulky evidence remain on bobo5090 at /data/lhq/workspace/ljl-v1-downstream-insertions.
