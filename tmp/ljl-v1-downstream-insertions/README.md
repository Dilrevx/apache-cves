# Strict v1 Downstream Insertions

This directory contains lightweight metadata and verifier scripts for strict vulnerability-triangle samples.

Definition used here: generated vulnerable upstream library v1 is inserted into a real downstream project runtime, then triggered through the downstream project own entrypoint with positive and negative dynamic evidence.

The full extracted runtimes and bulky evidence remain on bobo5090 at /data/lhq/workspace/ljl-v1-downstream-insertions and are intentionally not committed here.
